# Evidencia privada de aprendizaje

Esta carpeta define la convención del portafolio. Sus subcarpetas personales están ignoradas por Git para evitar publicar accidentalmente datos, fotografías, planos o trabajos no destinados a difusión.

## Inicio rápido

1. Copia [`templates/evidencia-clase.md`](../templates/evidencia-clase.md) a `evidence/ARQ-XXX/evidencia.md`.
2. Conserva la primera versión.
3. Registra crítica y correcciones en `revision.md`.
4. Para talleres usa `evidence/EST-XX/01` a `06`.

Consulta [Portafolio y evidencias](../docs/PORTAFOLIO_Y_EVIDENCIAS.md).
