# Parte 04 — Personas, investigación y programa arquitectónico

**Fase I · formación transversal · 10 clases · ARQ-031 → ARQ-040**

Esta parte comienza con **Del pedido del cliente a un programa de necesidades** y culmina con **Validación del programa y control de cambios**. Las diez clases forman una secuencia: cada una declara su pregunta, resultado, caso o práctica, fuentes y límites.

> Material educativo independiente. Este bloque no habilita para diseñar, calcular, firmar, autorizar ni ejecutar obras. Los parámetros de los casos no se transfieren a un proyecto real sin antecedentes, normativa y especialistas competentes.

## Problemas que articula

- **ARQ-031:** Cuando alguien pide «una sala para cuarenta personas», ¿qué información tienes realmente? 
- **ARQ-032:** ¿Cómo conocer las necesidades de quienes usan un espacio sin confundir nuestras suposiciones con su experiencia?
- **ARQ-033:** ¿Cómo transformar una lista de actividades en relaciones espaciales sin dibujar habitaciones demasiado pronto?
- **ARQ-034:** ¿Por qué diseñar para una persona “promedio” puede producir un espacio que no funciona para muchas personas reales?
- **ARQ-035:** ¿Cómo ofrecer privacidad y apoyo sin aislar a las personas ni convertir diferencias culturales en estereotipos de diseño?
- **ARQ-036:** ¿Cómo puede un edificio apoyar distintas etapas de la vida sin convertir la edad en una explicación automática de lo que una persona puede hacer?
- **ARQ-037:** ¿Por qué una sala puede tener una temperatura aparentemente adecuada y seguir resultando incómoda para quienes la usan?
- **ARQ-038:** ¿Cómo puede una comunidad influir de manera comprensible en un proyecto sin que una reunión se presente como aprobación de todas las personas?
- **ARQ-039:** ¿Qué necesita un espacio para admitir cambios de uso de verdad, y no solamente recibir la etiqueta de “flexible”?
- **ARQ-040:** ¿Cómo saber que un programa arquitectónico responde al encargo y cómo evitar que sus cambios destruyan decisiones ya justificadas?

### ARQ-031 · decisión sustentada

**Necesidad:** Esta clase existe para resolver una necesidad concreta del recorrido: Cuando alguien pide «una sala para cuarenta personas», ¿qué información tienes realmente? Conoces una intención y un número, pero no necesariamente la actividad, la simultaneidad, el mobiliario, la circulación ni las condiciones de acceso.

**Posición:** Abre la Parte 04 porque plantea primero el problema «Cuando alguien pide «una sala para cuarenta personas», ¿qué información tienes realmente? Conoces una intención y un número, pero no necesariamente la actividad, la simultaneidad, el mobiliario, la circulación ni las condiciones de acceso.». La transición desde ARQ-030 · Modelos discretos, cálculo numérico y validación conserva métodos de evidencia y límites, pero no traslada parámetros del bloque anterior. Establece la pregunta y el producto base que ARQ-032 · Entrevistas, observación y consentimiento desarrollará a continuación.

**Entrada:** ARQ-030 · **Salida:** ARQ-062, ARQ-066, ARQ-131, ARQ-032.

**Evidencia:** Construirás un programa de necesidades que distinga usuarios, actividades, requisitos, preferencias e incertidumbres. La evidencia será una matriz de ocho requisitos y un diagrama de relaciones. Para esta clase no se asignan superficies mínimas legales ni cargas de ocupación: deben investigarse después según el uso y la jurisdicción.

## Cómo recorrer esta parte

1. Lee las clases en orden cuando el tema sea nuevo; la continuidad está escrita dentro de cada documento.
2. Conserva separados dato, hipótesis, cálculo, evidencia, responsabilidad y autorización.
3. Resuelve la práctica independiente antes de abrir la solución orientativa o autoevaluación.
4. Revisa el apartado **Fuentes y alcance de uso**: una referencia apoya una afirmación delimitada, no certifica el caso completo.
5. Registra toda incertidumbre que cambiaría la decisión; “desconocido” no equivale a cero, seguro ni conforme.
