# Parte 82 — Proyecto, presupuesto detallado, compras y autorización

**Fase IV · aplicación práctica para propietarios · 10 clases · ARQ-811 → ARQ-820**

Esta parte comienza con **Levantamiento con medidas, cotas, deslindes, superficies y fotografías** y culmina con **Cronograma, compras, ruta crítica y autorización para iniciar**. Las diez clases forman una secuencia: cada una declara su pregunta, resultado, caso o práctica, fuentes y límites.

> Material educativo independiente. Este bloque no habilita para diseñar, calcular, firmar, autorizar ni ejecutar obras. Los parámetros de los casos no se transfieren a un proyecto real sin antecedentes, normativa y especialistas competentes.

La transición hacia ARQ-821 · Instalación de faenas, protección de lo existente, cierres, vecinos, accesos y acopios transfiere el método y la disciplina de evidencia, no los datos o parámetros particulares de esta parte.
