# Licencias y procedencia de datos

Inventario revisado el **2026-10-06**.

| Ruta | Naturaleza | Licencia o condición |
|---|---|---|
| `data/program.json` | Manifiesto canónico de edición, conteos, fases y línea base histórica | Selección y estructura originales bajo `CC BY-NC-SA 4.0` |
| `data/parts.json` | Títulos canónicos de las 84 partes curriculares | Selección y estructura originales bajo `CC BY-NC-SA 4.0` |
| `data/catalog.json` | Índice editorial de las 840 clases | Selección y estructura originales bajo `CC BY-NC-SA 4.0` |
| `data/pedagogy.json` | Contrato de evaluación, diez talleres y treinta y cinco rutas | Selección y estructura originales bajo `CC BY-NC-SA 4.0` |
| `data/pedagogical-decisions.json` | Contratos pedagógicos revisados y trazabilidad de clases piloto | Selección y estructura originales bajo `CC BY-NC-SA 4.0` |
| `data/pedagogical-decisions-generated.json` | Cadenas de decisión de las 840 clases derivadas de pregunta, resultado, práctica, fuentes y vecindad curricular | Salida reproducible bajo `CC BY-NC-SA 4.0` |
| `data/audits/class-distinctness.json` y `docs/audits/class-distinctness.csv` | Resultados derivados de la comparación editorial de las 840 clases | Salida reproducible bajo `CC BY-NC-SA 4.0`; métricas descriptivas, no certificación de calidad |
| `data/verificacion.json` | Registro de afirmaciones normativas verificadas contra texto oficial, con instrumento, nivel de lectura y clases de uso | Selección y estructura originales bajo `CC BY-NC-SA 4.0`; los textos normativos citados mantienen su condición de obras oficiales y no se reproducen, solo se parafrasean |
| `data/vigilancia.json` | Lista de fuentes oficiales vigiladas, con frecuencia de revisión y clases o fichas que dependen de ellas | Selección y estructura originales bajo `CC BY-NC-SA 4.0`; localizadores de terceros sin licenciamiento propio |
| `sources/bibliography.json` | Registro generado de URLs, títulos, procedencia inferida, consulta, función, licencia y clases que las usan | Selección y estructura bajo `CC BY-NC-SA 4.0`; los hechos, localizadores y obras enlazadas mantienen su condición jurídica; recursos externos `link-only` salvo evidencia distinta |
| `STATUS_v1.0.json` | Fotografía histórica del estado de la entrega v1.0 | `CC BY-NC-SA 4.0` |
| Inventarios embebidos en el lector v1.0 | Roles, rutas, plantillas, documentos y fichas de fuente | Contenido editorial original bajo `CC BY-NC-SA 4.0`; referencias externas excluidas |

No se versionan datasets de obra, expedientes profesionales, datos personales ni mediciones reales. Si una contribución incorpora datos, debe documentar fuente, permiso, licencia, finalidad y método de minimización antes de aceptarse.
