# Política de seguridad

Este repositorio publica material educativo y un generador estático. Si detectas una vulnerabilidad en los scripts, workflows o sitio, usa **Security → Report a vulnerability** en GitHub y evita incluir datos personales, credenciales o información de terceros en un issue público.

Los ejemplos del currículo no autorizan inspecciones, ensayos, intervenciones ni obras reales. Toda actividad profesional debe contar con competencias, responsabilidades, permisos, procedimientos y normativa aplicables al caso y a su jurisdicción.
