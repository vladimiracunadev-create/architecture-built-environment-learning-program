# Glosario acumulativo español–inglés

El glosario sirve para conectar conceptos, no para reemplazar las clases. Cada entrada incluye traducción funcional, contexto, relación y un ejemplo de acceso. Las traducciones pueden variar entre jurisdicciones y disciplinas.

| Término | Inglés | Definición y contexto | Relaciones | Clase de entrada |
|---|---|---|---|---|
| accesibilidad | accessibility | posibilidad de llegar, comprender, usar y evacuar con autonomía y apoyos adecuados | diseño universal, wayfinding, dignidad | [ARQ-171](../classes/parte-18/ARQ-171.md) |
| adaptación climática | climate adaptation | ajuste ante clima observado o esperado para reducir daño y aprovechar oportunidades compatibles | riesgo, escenarios, resiliencia | [ARQ-761](../classes/parte-77/ARQ-761.md) |
| as-built | as-built record | documentación actualizada que registra lo efectivamente construido dentro del alcance comprobado | entrega, control de cambios, operación | [ARQ-410](../classes/parte-41/ARQ-410.md) |
| BIM | building information modelling | gestión de información del activo mediante requisitos, modelos, procesos, responsabilidades y versiones | IFC, CDE, gemelo digital | [ARQ-431](../classes/parte-44/ARQ-431.md) |
| brecha de desempeño | performance gap | diferencia entre desempeño previsto y observado bajo fronteras comparables | simulación, medición, posocupación | [ARQ-288](../classes/parte-29/ARQ-288.md) |
| camino de cargas | load path | continuidad por la que acciones y reacciones se transmiten hasta el terreno | equilibrio, conexión, fundación | [ARQ-191](../classes/parte-20/ARQ-191.md) |
| carbono incorporado | embodied carbon | emisiones asociadas a productos, construcción, reposición y fin de vida según frontera declarada | ACV, EPD, unidad funcional | [ARQ-443](../classes/parte-45/ARQ-443.md) |
| CDE | common data environment | entorno acordado para gestionar información, estados, versiones, permisos y revisiones | BIM, coordinación, trazabilidad | [ARQ-433](../classes/parte-44/ARQ-433.md) |
| circularidad | circularity | estrategia para conservar valor, reducir extracción y diseñar mantenimiento, adaptación, desmontaje y reuso | ciclo de vida, bancos de materiales | [ARQ-447](../classes/parte-45/ARQ-447.md) |
| clash detection | clash detection | comprobación de interferencias geométricas o lógicas dentro de un uso y reglas definidos | BIM, coordinación, falsos positivos | [ARQ-435](../classes/parte-44/ARQ-435.md) |
| confort | comfort | experiencia situada influida por condiciones térmicas, acústicas, lumínicas, de aire y control personal | habitabilidad, percepción, medición | [ARQ-037](../classes/parte-04/ARQ-037.md) |
| deconstrucción | deconstruction | desmontaje planificado para recuperar componentes y materiales con seguridad y trazabilidad | fin de vida, reuso, residuos | [ARQ-779](../classes/parte-78/ARQ-779.md) |
| diseño generativo | generative design | exploración algorítmica de alternativas bajo reglas, variables y objetivos declarados | parametrización, optimización, IA | [ARQ-717](../classes/parte-72/ARQ-717.md) |
| EPD | environmental product declaration | declaración ambiental basada en reglas y alcance específicos; no equivale por sí sola a superioridad | ACV, comparabilidad, producto | [ARQ-444](../classes/parte-45/ARQ-444.md) |
| evidencia | evidence | observación, medición, cálculo, fuente o registro que permite sostener una afirmación dentro de límites | trazabilidad, incertidumbre, revisión | [ARQ-008](../classes/parte-01/ARQ-008.md) |
| gemelo digital | digital twin | representación conectada con datos y propósito operativo explícito; no es cualquier modelo 3D | sensores, operación, ciberseguridad | [ARQ-728](../classes/parte-73/ARQ-728.md) |
| habitabilidad | habitability | capacidad del entorno para sostener vida, salud, actividades, dignidad y adaptación | vivienda, confort, accesibilidad | [ARQ-149](../classes/parte-15/ARQ-149.md) |
| HBIM | heritage building information modelling | uso de información y modelos para documentar y gestionar patrimonio existente | escaneo, archivo, conservación | [ARQ-774](../classes/parte-78/ARQ-774.md) |
| hipótesis | hypothesis | proposición provisional que puede contrastarse y corregirse con evidencia | pregunta, método, falsación | [ARQ-682](../classes/parte-69/ARQ-682.md) |
| IFC | Industry Foundation Classes | esquema abierto para intercambio de información del entorno construido | openBIM, semántica, interoperabilidad | [ARQ-434](../classes/parte-44/ARQ-434.md) |
| interoperabilidad | interoperability | capacidad de intercambiar y usar información conservando significado y propósito | IFC, clasificación, requisitos | [ARQ-434](../classes/parte-44/ARQ-434.md) |
| LOD | level of development/detail | convención cuyo significado debe acordarse para un uso, entrega y responsabilidad concretos | BIM, requisitos, aceptación | [ARQ-432](../classes/parte-44/ARQ-432.md) |
| mantenimiento | maintenance | acciones para conservar o recuperar función, seguridad y desempeño durante el uso | inspección, criticidad, ciclo de vida | [ARQ-464](../classes/parte-47/ARQ-464.md) |
| modelo | model | representación selectiva construida para responder una pregunta; siempre conserva supuestos y frontera | simulación, validación, error | [ARQ-199](../classes/parte-20/ARQ-199.md) |
| nivel de servicio | level of service | condición observable con que una infraestructura presta una función a usuarios y territorio | capacidad, continuidad, equidad | [ARQ-751](../classes/parte-76/ARQ-751.md) |
| openBIM | openBIM | enfoque de colaboración basado en estándares y procesos abiertos, con usos y responsabilidades acordados | IFC, IDS, bSDD | [ARQ-434](../classes/parte-44/ARQ-434.md) |
| patología | building pathology | manifestación de daño cuyo diagnóstico exige diferenciar síntoma, mecanismo, causa y condición | humedad, fisura, reparación | [ARQ-453](../classes/parte-46/ARQ-453.md) |
| posocupación | post-occupancy evaluation | evaluación sistemática del edificio en uso mediante desempeño y experiencia de personas | medición, operación, retroalimentación | [ARQ-470](../classes/parte-47/ARQ-470.md) |
| prerrequisito | prerequisite | capacidad o evidencia necesaria antes de abordar una decisión posterior | diagnóstico, nivelación, dependencia | [Mapa](MAPA_DE_DEPENDENCIAS.md) |
| programa arquitectónico | architectural brief/program | traducción del encargo a actividades, relaciones, requisitos y criterios verificables | brief, usuario, cambio | [ARQ-031](../classes/parte-04/ARQ-031.md) |
| RFI | request for information | solicitud documentada para aclarar información sin ocultar alcance, respuesta, fecha y efecto | obra, contrato, cambio | [ARQ-408](../classes/parte-41/ARQ-408.md) |
| resiliencia | resilience | capacidad de anticipar, resistir, adaptarse, recuperar funciones y aprender ante perturbaciones | riesgo, continuidad, redundancia | [ARQ-369](../classes/parte-37/ARQ-369.md) |
| riesgo | risk | interacción de amenaza, exposición, vulnerabilidad y capacidad dentro de un contexto | incertidumbre, escenario, gobernanza | [ARQ-371](../classes/parte-38/ARQ-371.md) |
| sensibilidad | sensitivity analysis | examen de cuánto cambia un resultado cuando se modifica una entrada o supuesto | modelo, incertidumbre, robustez | [ARQ-420](../classes/parte-42/ARQ-420.md) |
| submittal | submittal | entrega contractual para revisión o registro cuyo efecto depende del contrato y del flujo aprobado | muestra, ficha, responsabilidad | [ARQ-407](../classes/parte-41/ARQ-407.md) |
| trazabilidad | traceability | posibilidad de reconstruir una decisión desde resultado hasta datos, fuentes, versiones y responsables | evidencia, control de cambios | [ARQ-138](../classes/parte-14/ARQ-138.md) |
| unidad funcional | functional unit | servicio cuantificado que permite comparar alternativas dentro de fronteras equivalentes | ACV, desempeño, vida útil | [ARQ-441](../classes/parte-45/ARQ-441.md) |
| validación | validation | comprobación de que la solución sirve para el uso previsto bajo condiciones declaradas | verificación, usuario, prueba | [ARQ-136](../classes/parte-14/ARQ-136.md) |
| verificación | verification | comprobación de que una salida satisface requisitos y reglas definidos | cálculo, inspección, prueba | [ARQ-200](../classes/parte-20/ARQ-200.md) |
| wayfinding | wayfinding | sistema espacial, sensorial e informativo que permite orientarse y decidir recorridos | señalética, legibilidad, accesibilidad | [ARQ-175](../classes/parte-18/ARQ-175.md) |

Para ampliar una entrada debe añadirse una relación útil y un enlace a una clase; no se incorporan definiciones aisladas para aumentar el conteo.
