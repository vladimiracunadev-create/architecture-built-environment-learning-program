# Cómo usar el programa

## Elige una entrada

| Si eres… | Empieza por… | Después |
|---|---|---|
| estudiante desde cero | Partes 01–04 | sigue la Fase I en orden |
| estudiante de arquitectura | parte que corresponda a tu taller | vuelve a fundamentos, sitio y sistemas cuando aparezca una brecha |
| docente | README de cada parte | selecciona preguntas, casos y prácticas; adapta evaluación y tiempo |
| profesional de otra especialidad | [roles y oficios](ROLES_Y_OFICIOS.md) | recorre interfaces, responsabilidades y límites |
| mandante o gestor de activos | Ruta 12 | continúa con costos, contratos, operación y mantenimiento |
| lector interesado en una tipología | Partes 49–68 | no copies parámetros sin revisar Partes 01–48 |

## Método recomendado

1. Lee la **pregunta central** antes de las explicaciones.
2. Identifica el **resultado o entrega** y qué continuidad propone la clase.
3. Separa datos, hipótesis, parámetros ficticios y condiciones desconocidas.
4. Reconstruye el **caso trabajado** y comprueba unidades, fronteras y supuestos.
5. Resuelve la **práctica independiente** antes de consultar la solución.
6. Revisa **fuentes y alcance de uso**; anota qué podría cambiar la conclusión.
7. Registra responsabilidades: quién propone, calcula, revisa, autoriza, construye, opera y mantiene.

## Tres maneras de recorrerlo

### Secuencia completa

ARQ-001 → ARQ-680. Recomendada cuando se busca una formación transversal y se dispone de tiempo para seguir dependencias.

### Por parte

Cada carpeta tiene un README con sus diez preguntas, resultados y enlaces. Es la mejor entrada para estudiar un bloque sin perder su contexto.

### Por ruta

Las doce rutas conectan partes no contiguas alrededor de una responsabilidad: fundamentos, proyecto integral, historia y patrimonio, territorio, estructuras, construcción, gestión, desempeño, BIM, sostenibilidad, operación o mandante.

## Qué conservar como evidencia de aprendizaje

- registro de decisiones y cambios;
- comparación de alternativas;
- desarrollo de cálculos con unidades;
- croquis, diagramas o modelos con alcance;
- fuente exacta y límite de uso;
- incertidumbres abiertas;
- autoevaluación y correcciones;
- entrega final que otra persona pueda revisar.

No uses el repositorio como expediente de obra ni como sustituto de documentos firmados, permisos o revisión competente.
