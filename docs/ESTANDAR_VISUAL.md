# Estándar visual y de representación

## Propósito

La arquitectura no puede enseñarse únicamente mediante prosa. Cada clase incorpora un mapa visual de su ciclo de aprendizaje y, cuando el tema lo requiere, debe añadir representación disciplinar: planta, corte, axonometría, detalle, mapa, cronología, diagrama de cargas, flujo, secuencia o matriz.

## Reglas

1. Toda figura responde una pregunta identificable.
2. Escala, orientación, unidades, leyenda, fuente y estado deben aparecer cuando sean pertinentes.
3. Una imagen ilustrativa no se presenta como evidencia del caso.
4. Color nunca es el único medio para distinguir estados.
5. El texto alternativo explica la relación importante, no repite el título.
6. No puede existir una leyenda “Figura” sin un activo o diagrama visible.
7. Las representaciones sintéticas se rotulan como elaboración del programa.
8. Planos, fotografías o capturas de terceros requieren fuente y licencia compatible.

## Jerarquía

- **Mapa de aprendizaje:** obligatorio en 680 clases; explica pregunta, método, transferencia, evidencia y revisión.
- **Representación disciplinar:** obligatoria en clases donde forma, espacio, secuencia o relación técnica no se comprenden adecuadamente mediante texto.
- **Lámina de parte:** integra las diez clases y sus dependencias.
- **Portafolio:** conserva versiones y no solo imágenes finales.

## Accesibilidad

Los diagramas deben ser legibles a 200 % de zoom, funcionar con teclado cuando sean interactivos, mantener contraste suficiente y conservar una explicación textual equivalente.
