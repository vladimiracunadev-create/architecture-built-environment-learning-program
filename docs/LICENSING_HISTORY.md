## Consecuencias

- Una copia histórica debe evaluarse según los archivos y permisos disponibles en esa revisión; este repositorio no inventa autorización retroactiva.
- Las licencias públicas válidamente concedidas para una revisión no se revocan por cambios posteriores.
- La fecha de un commit prueba el contenido del repositorio en ese punto, no por sí sola la titularidad de cada obra externa citada.
- El historial observado atribuye los seis commits anteriores a esta auditoría a Vladimir Acuña (`vladimiracunadev-create`). No se detectaron otros autores de commit en ese tramo; ello no reemplaza una investigación externa de titularidad.

La referencia técnica es el historial Git; la interpretación jurídica de situaciones concretas requiere revisión profesional independiente.
