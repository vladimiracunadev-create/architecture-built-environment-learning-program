# Uso comercial y permisos separados

Este documento explica el régimen publicado; no concede por sí mismo permisos adicionales ni constituye asesoría jurídica.

## Código

El código propio, los scripts, workflows, configuraciones, estilos y componentes funcionales identificados en la [matriz de licencias](LICENSING_MATRIX.md) están bajo Apache License 2.0. Esa licencia permite uso, modificación, distribución y explotación comercial si se cumplen sus condiciones, incluidos los avisos aplicables y la indicación de archivos modificados.

## Contenido pedagógico

Las clases, explicaciones, ejercicios, casos, rutas, plantillas y metodología editorial originales se ofrecen públicamente bajo CC BY-NC-SA 4.0. La licencia pública no autoriza usos principalmente dirigidos a ventaja comercial o compensación monetaria. La atribución y el compartir igual siguen siendo obligatorios cuando corresponda.

El titular de los derechos puede ofrecer, mediante un acuerdo independiente, permisos comerciales sobre el contenido original que esté facultado para licenciar. Esa posibilidad no revoca la licencia CC ya concedida ni amplía derechos sobre material de terceros.

## Exclusiones

Ningún permiso comercial del proyecto puede incluir automáticamente normas, papers, libros, fotografías, planos, documentación de fabricantes, marcas, datos o cualquier otra obra de terceros. Cada componente requiere revisar su titularidad y sus términos.

La marca y `assets/mark.svg` tienen capas distintas: la licencia de copyright del gráfico no concede una licencia de marca ni permite presentar un fork como oficial.

## Aplicaciones y servicios futuros

Una aplicación, API o SaaS puede desarrollarse en otro repositorio y usar el código Apache-2.0 respetando sus condiciones. Para incorporar el contenido CC de este repositorio en una oferta comercial se necesita analizar la licencia pública o acordar un permiso separado con los titulares pertinentes. No es necesario convertir este repositorio educativo en un producto comercial ni cerrar su código para que exista ese desarrollo independiente.

Para consultar permisos distintos a los publicados, abre un canal de contacto con el titular identificando componentes, finalidad, territorio, duración, modificaciones y forma de distribución. La ausencia de respuesta no concede permiso.
